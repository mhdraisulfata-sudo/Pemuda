# Pemuda Aceh — Jelajahi Aceh dengan Nyaman

Aplikasi web prototipe untuk eksplorasi wisata Aceh, kuliner lokal, akomodasi ramah Muslim, perencanaan itinerary, kalkulator anggaran, serta dashboard manajemen konten lokal (berbasis `localStorage`).

## Fitur Utama

- **Eksplorasi Destinasi**: Pencarian, filter wilayah & kategori, serta pengurutan (unggulan, alfabet, biaya terendah).
- **Favorit Saya**: Simpan dan kelola destinasi, kuliner, serta akomodasi favorit di browser.
- **Peta Ilustratif Aceh**: Orientasi awal wilayah wisata Aceh dengan tautan cepat ke Google Maps.
- **Kuliner & UMKM Lokal**: Informasi produk kuliner lokal beserta status verifikasi halal secara transparan.
- **Akomodasi Ramah Muslim**: Informasi fasilitas penginapan dan dukungan kebutuhan wisatawan Muslim.
- **Rancang Perjalanan (Trip Planner)**:
  - Penyusunan itinerary 1–5 hari.
  - Kalkulator estimasi anggaran otomatis (destinasi, makan, penginapan).
  - Rekomendasi paket wisata berbasis minat, durasi, dan batas anggaran.
  - Ekspor itinerary ke JSON, salin ringkasan teks, dan cetak rencana perjalanan.
- **Dashboard Pengelola**: CRUD lokal untuk data destinasi, kuliner, akomodasi, dan paket wisata.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
```
